THE THROUGH-LINE

Understand the system.
Then make it useful.

I’m an engineer in Madrid who tends to get interested in the layer underneath the obvious one. If a product uses an LLM, I want to understand the inference stack. If a security tool sees an executable, I want to understand the binary. If software involves music, I probably want to build the mixer too.

I work across AI, cybersecurity and systems, but the recurring thread is making complex things legible and useful. I like local-first tools, open-ended problems and building from first principles—whether the result supports a serious security workflow or helps friends put songs in the right order.
